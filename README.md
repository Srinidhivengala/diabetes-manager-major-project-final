# Diabetes Management Flask App

A local-first Flask web application for:

- Diabetes risk classification  
- Glucose forecasting  
- SHAP explainability  
- Dual dashboards (Patient & Clinician)

---

## 🚀 Features

- Risk classification from PIMA-style inputs
- Glucose forecasting (CGM CSV or manual)
- SHAP explainability (feature contributions)
- Dual dashboards:
  - Patient dashboard
  - Clinician dashboard
- Offline-friendly (runs locally)
- SQLite database
- Role-based authentication
- CSV/PDF export
